# 디자인 시안 인덱스

GPT-Image로 생성한 UI 시안 모음. 구현 시 이 시안을 기준으로 디자인 토큰과 위젯을 작성한다.

## 디자인 톤 (시안 기준)

- **배경**: 거의 흰색에 가까운 매우 옅은 크림 (`#FFFFFF` ~ `#FAFAFA`) — 기존 토큰 `#FFF8F0`보다 더 화이트
- **Primary 오렌지**: `#FF6B35` 계열 (CTA 버튼, 강조 텍스트, 활성 칩)
- **Secondary 민트**: `#2EC4B6` 계열 (항아리 마스코트)
- **카테고리 색 도트**: 채소(초록), 유제품(파랑), 육류(빨강/핑크), 양념(주황) 등 카테고리별 컬러 도트
- **카드**: 흰 배경 + 매우 옅은 그림자 + 라운드 16~20
- **폰트**: 굵은 한글 (Pretendard Bold/SemiBold), 본문 Regular
- **마스코트**: 민트색 항아리 + 작은 눈/입 + 손잡이 — 앱 전반에 등장

- 화면 작업 시 `@docs/design/0X_xxx.png` 형식으로 채팅에 첨부 → AI가 시안을 보고 정확한 위젯 코드 작성
